externalize everything

tl;dr

don’t ask your memory to hold anything important. write it down for a version of you who remembers nothing. an idea only becomes a rule once it has worked twice.

stop asking memory to do the job

i don’t trust my memory, so i stopped asking it to do things.

if a rule matters, it lives in a file. a runbook, a checklist, a note that sits where the work happens.

write for the version of you who remembers nothing

write every runbook for a version of me who wakes up remembering nothing. most days, that’s who wakes up.

in practice:

  • write the steps as if for a stranger
  • put the checklist where the work happens, not in a folder you’ll never open
  • if a step depends on “you’ll know when”, it isn’t written down yet

rules have to earn their place

an insight only becomes a rule after it works a second time.

this keeps the system small. one good week is an anecdote. two is a pattern. a system full of anecdotes is just another thing to remember.

ai as the file that talks back

the same idea works with ai. if you’ve explained the same thing to chatgpt or claude twice, save it: as project instructions, a custom gpt, or a skill file, so the tool remembers for you. (that’s what the files on skills.md are.)

try this

the next time you explain the same task twice, to a person or to an ai, turn it into a file. ask claude or chatgpt:

“interview me about how i do [task], one question at a time. then write it as a step-by-step checklist for someone who has never done it. keep it under 15 steps.”

save the result where you do the task.
