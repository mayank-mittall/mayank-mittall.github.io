the adhd thing

the adhd thing.

i have adhd. this page is what i do about it. not the motivational-poster version. the 2am version.

if you’re here because a linkedin post felt like being personally attacked: welcome. you’re among friends.

not a superpower. not a disability.

the internet needs adhd to be one of two things, a tragedy or a cheat code. it’s neither. it’s a brain that can’t start without pressure and can’t stop once it does. it forgets the thing it loves and locks onto the thing it doesn’t. it sees the pattern faster than it can explain it, then forgets to send the email explaining it. the output is real. the bill is real. every system below exists so i pay the bill on purpose instead of by surprise.

what i actually do.

  • 01externalize everything

    if a rule matters, it’s a file, not a memory.

  • 02nets, not resolutions

    every workflow has a second place the dropped ball lands.

  • 03manufacture pressure

    make the deadline real before you need it.

  • 04one capture point

    one inbox for every stray thought. mine is a slack dm to myself.

  • 05spend hyperfocus, don’t fight it

    mine the lock-in. the bill is sleep.

  • 06own the range

    six fields in seven years was one diagnostic, run on a new funnel each time.
